# Historical design and validation receipts

These snapshots preserve the documentation as it stood before consolidation on
2026-10-11, including exact revisions, failed attempts, validation output and
the detailed work-package handoffs. They are retained evidence, not live status
or new permission to execute a procedure.

| Snapshot | Contains | Live replacement |
|---|---|---|
| [Implementation roadmap](Implementation_Roadmap_2026-10-11.md) | Dated deliveries, source/PR boundaries, original/rebase test receipts and detailed sequencing | [Current roadmap](../Implementation_Roadmap.md) |
| [Deferred validation](Deferred_Validation_2026-10-11.md) | Dated proof batches, failed/blocked trials, approval scopes and detailed operator procedures | [Current validation register](../Deferred_Validation.md) |

The original headings and receipt text are retained; relative links are adjusted
for the new directory. New trials belong in new evidence records, not edits that
relabel historical results. Existing experiment and checked-in evidence artifacts
remain in their original locations.

For current requirements, use the [design index](../README.md) and the
[qualification policy](../Acceptance_Criteria.md#three-tier-qualification-policy).
