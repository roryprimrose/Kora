# Ask about one MCP observation

After a successful reviewed, host-mapped read-only MCP operation, expand
**Ask a new question about this exact MCP observation** immediately below its
result in Sessions. This is separate from Reply to an ASSISTANT message: a
model-free MCP result is not an assistant answer.

Enter a new bounded question in the independent, memory-only question field.
Choose **Review complete observation and question**. Inspect the complete
unchanged Text and StructuredJson (when present), actual server, delegated
account, tool/schema, observation time and original source channel, exact
currently selected Active conversation, question, locality and retention.
Nothing is truncated to fit. An oversized complete serialized context is refused.

Only a separate **Consent to ONE local-only tool-free answer** permits submission.
The spent invocation grant is neither reused nor renewed and is not model-use
consent. Source-use classification, current cached source/account/permission,
call/privacy/ownership admission and an independently qualified local model
remain mandatory. The production source-use seam currently reports
**Unavailable**; deterministic qualified fixtures are not production enablement.
Unknown classification or qualification never falls back to a hosted model.

An admitted turn uses the canonical conversation submission path and retains
only the exact new question and genuine final answer or truthful HOST terminal
in that exact conversation. It does not retain an extra copy of the raw source,
invoke or refresh MCP, read the source again, enable tools, write memory or export.
Text resembling instructions, scripts or session identifiers stays inert.
The original source channel is checked separately from the question channel;
typing a question cannot relabel a voice-origin source.

Changing the source, account, server, question, selection or private presentation
retires the review. Replacing a result with identical text requires a fresh
review and consent. Cancel or close immediately retires private review/use and
joins owned work, including a provider that ignores cancellation. Processing
already performed is not rolled back and bytes already sent cannot be retracted.
An unconfirmed completion remains held without automatic retry, even after
Cancel or a new review. Ordinary unsent conversation input stays independent.
